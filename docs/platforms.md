# 平台兼容与真实边界

以下方法来自本地工作流历史实践（整理于 2026-11-02），不是对任意账号和当前网站的成功保证。公开包提供方法和只读探针，真实执行由 Agent 根据页面适配。

| 平台 | 找岗方法 | 投递/联系方法与边界 |
|---|---|---|
| BOSS直聘 | 官网岗位搜索；列表 `.job-card-box` / `.job-card-wrapper`，详情 `.job-sec-text`；薪资字体编码时读真实详情 | 精确岗位建立会话后发送定制正文；双方回复前 PDF 可能不可发，图片能力须实测。消息/图片需刷新回读 |
| 猎聘 | 官网搜索；兼容 `jobCardPcContainer` 卡片；详情读取职责及任职要求 | 正式申请与聊天分开记；“聊一聊”可能自动发送默认招呼，执行前判断副作用；认证限制需正常恢复 |
| 智联招聘 | 搜索列表与详情；历史原生列表组件含完整 JD，DOM选择器变更后重新检查 | 正式申请、聊天、简历审核各记状态；不可由列表显示登录推断完整详情与发送均可用 |
| 前程无忧 | 搜索列表及原生详情；移动详情匿名可读不代表已登录 | 正式申请历史可回读；网页聊天可能仅给扫码入口，申请成功不等于定制正文送达 |
| 脉脉 | 本人正常动态搜索→招聘卡→原生职位详情；动态检索不是全站职位库 | 好友申请、会话开通、正文、PDF 分开核验；免费额度/会员额度不同。远端可能压缩换行，须检查真实正文 |
| 求职小程序 | 按具体小程序正式入口读岗，保留岗位编号及完整 JD 副本 | 本公开流程仅保留本人手动投递。历史设备接入不等于可复制的无人值守自动投递 |

## 后台读取

`capture-page.mjs` 复用了原 CDP 新建独立 hidden target、DOM 读取和截图的方法，参数化端口与输出目录。当前探针覆盖五平台 URL 白名单和候选 JD 选择器；没有调用发送接口，不读 Cookie，不做全站爬取。支持的 Chrome 需能创建 `hidden` target，未支持时直接失败。调试端口只在本机使用。

探针给出的 `candidate_text` 仍需人工/Agent核对完整性。登录墙、遮挡、字数、滚动与来源页面需一起检查，选择器匹配不等于已获得完整 JD。不自动绕过验证码/限流，不自动点击登录或外发控件。

## 自动化接线

Agent 可使用自己已有的 Playwright/CDP/浏览器工具读取页面，按照 Skills 对目标原生控件操作。每个平台第一次发送前先检查当前真实界面、账号、岗位、HR 与副作用，不能照抄旧坐标。私人登录环境由使用者管理；不提供作者 profile、不复制 Cookie、不共享第三方账号。

不提供跨平台统一一键发送脚本，是因为现有实践依赖登录态、站点版本、HR关系、材料入口和逐岗远端回读。这里开放完整操作与验收方法，未将研究脚本宣称稳定 SDK。
